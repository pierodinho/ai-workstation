# AI Workstation — édition publique

Site statique en lecture seule. Le dossier `dist/` contient uniquement l'interface et une sélection de descriptions fonctionnelles publiques. Aucun serveur local, donnée d'inventaire brute, identité, chemin, version installée, identifiant matériel ou secret n'est nécessaire à son fonctionnement.

La publication est un instantané. Les mises à jour doivent repasser par une sélection et un contrôle des données. Aucun pilotage de PC, formulaire de collecte ou outil de mesure d'audience n'est inclus.
